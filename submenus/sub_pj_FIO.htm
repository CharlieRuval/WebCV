Package sorter
Back to projects
A comprehensive virtual simulation environment was developed in Factory I O to model and evaluate a package classification system under realistic operating conditions. The project included the synchronization of Factory I O with a dedicated Petri net library in MATLAB, enabling the integration of discrete event modeling with real time virtual processes. This synchronization ensured that the simulation accurately represented the behavior defined by the Petri net models and supported advanced supervisory control approaches.
Within the simulation, package classification by color was implemented by designing logic that detects, differentiates, and sorts items according to predefined categories. This functionality reflects common industrial sorting operations and required the coordinated use of virtual sensors in Factory I O together with event driven dynamics governed by Petri nets.
To enhance reliability, supervisory control methods for Petri net based systems were applied to ensure safe operation and to prevent undesired behaviors, including deadlocks and resource conflicts. The resulting control strategy improved workflow performance while maintaining compliance with defined system constraints.
Overall, this project demonstrates the integration of discrete event control theory, Petri net modeling in MATLAB, and the immersive simulation capabilities of Factory I O. The outcome is a robust and scalable platform for testing package classification processes, validating control logic, and supporting future implementation in real automated systems.
