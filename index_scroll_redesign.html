Wind turbine inspection

This project reviewed current practices for the visual inspection of wind turbine generators, with particular attention to the use of unmanned aerial vehicles in constrained or restricted environments. A structured inspection workflow was modeled using finite state machines to represent phases such as initialization, navigation, image acquisition, and return to launch.

To improve scalability and organization, the proposal separates high level planning from execution level behavior in a hierarchical discrete event system. Supervisory control methods were applied to regulate transitions and enforce safety conditions according to predefined logic.

Package sorter

A virtual package classification system was developed in Factory I O and synchronized with a dedicated MATLAB Petri net library. This integration allowed the real time simulation to follow discrete event behavior defined by the Petri net models.

Package sorting by color was implemented using virtual sensors and event driven logic. Supervisory control methods were then applied to prevent deadlocks, reduce resource conflicts, and maintain safe operation under realistic workflow conditions.

Hospital design

A hospital layout was drafted in AutoCAD to support a safe, functional, and efficient healthcare environment aligned with NOM 001, NOM 002, NOM 007, NOM 016, and NOM 087. The design considered architectural, structural, electrical, and biosafety requirements.

Lighting distribution, medical gas routing, emergency safety conditions, and hazardous biological waste management were integrated to support reliable clinical operations and patient safety.

Automation training infrastructure

New laboratory infrastructure was designed to strengthen automation training, including pneumatic components modeled in SolidWorks, fabricated acrylic based assemblies, instrument calibration, and technical documentation.

The work also included adapting a pneumatic robot arm for PLC control, creating a more industry oriented platform for teaching practical automation. This initiative supported the registration of an industrial design model before the Instituto Mexicano de la Propiedad Industrial.

AR robotics app for Android

An augmented reality application was built in Unity for Android devices to visualize and control robotic platforms through an interactive interface. The system presents device data and uses digital controls for user interaction.

Animated models of an omnidirectional vehicle, a quadcopter, and a SCARA robot were created from SolidWorks references. Finite state machines coordinated behavior while kinematic models supported consistent robotic motion in local and global coordinate frames.
